# About This Portfolio

## Purpose

To showcase practical software engineering work and skill depth, with emphasis on backend APIs, cloud-native architecture, and real-time systems.

## Featured Projects

1. Cloud-Native Task Management System

## Structure

- `src/App.jsx`: React page structure and portfolio content
- `src/styles.css`: visual design system and responsive layouts
- `src/main.jsx`: React entry point

## Design Goals

- Professional visual language
- Readable content hierarchy
- Fast load and simple deployment
- Responsive behavior without framework overhead
